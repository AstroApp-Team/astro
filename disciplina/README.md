# Disciplina — ENG4030 Projeto Integrador 3

Esta pasta guarda o que é da disciplina, não do código: planejamentos,
rascunhos de entrega e decisões de negócio que o grupo toma ao longo das
sprints. Nada aqui é lido pelo app nem pelo build.

O resto do repositório é o MVP funcional do Astro. Aqui fica o porquê de ele
existir e como vamos testá-lo com gente de verdade.

## Organização

Uma pasta por sprint, com um arquivo por entregável:

```
disciplina/
  sprint-3/
    planejamento-mvp.md   planejamento do experimento com o MVP (Aula 9)
```

Os PDFs finais (relatório, apresentação, planilha) continuam sendo entregues
pelo canal da disciplina. O que vai aqui é o conteúdo em texto, para o grupo
editar e revisar como qualquer outra mudança do repositório.

## Convenções

- Em português, como as entregas.
- Sem detalhe técnico de implementação. Isso já está no `README.md` da raiz e
  no `AGENTS.md`; aqui o foco é cliente, hipótese e evidência.
- Números citados vêm das pesquisas das Sprints 1 e 2. Dados pessoais dos
  respondentes (e-mails etc.) não entram no repositório.
